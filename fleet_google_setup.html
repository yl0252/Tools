🔗 Google Sheets & Drive Setup

Connect your Fleet Manager to Google — takes about 5 minutes. No coding knowledge needed.

1
Create a Google Sheet

Go to sheets.google.com and create a new blank spreadsheet. Name it something like Fleet Manager Data.

Once it's open, look at the URL in your browser. It will look like this:

https://docs.google.com/spreadsheets/d/1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgVE2upms/edit

The long string of letters and numbers between /d/ and /edit is your Sheet ID. Copy it — you'll need it in the next step.

2
Open Google Apps Script

In your Google Sheet, click the menu: Extensions → Apps Script

A new tab will open with a code editor. You'll see a default function — delete everything in the editor and paste the code below.

⚠️ Important: Replace YOUR_GOOGLE_SHEET_ID on line 1 with the Sheet ID you copied in Step 1.
const SHEET_ID     = 'YOUR_GOOGLE_SHEET_ID';  // ← paste your Sheet ID here
const DRIVE_FOLDER = 'Fleet Photos';          // photos go in this Drive folder

function getOrCreateFolder(name){
  const folders = DriveApp.getFoldersByName(name);
  return folders.hasNext() ? folders.next() : DriveApp.createFolder(name);
}

function doGet(e){
  try{
    const ss = SpreadsheetApp.openById(SHEET_ID);
    const sh = ss.getSheetByName('FleetJSON');
    if(sh && sh.getLastRow() > 0){
      const chunks = sh.getRange(1,1,sh.getLastRow(),1).getValues();
      const json   = chunks.map(r => r[0]).join('');
      return ContentService.createTextOutput(json)
        .setMimeType(ContentService.MimeType.JSON);
    }
    return ContentService.createTextOutput(
      JSON.stringify({error:'No data yet. Save from the desktop tool first.'})
    );
  }catch(e){
    return ContentService.createTextOutput(JSON.stringify({error:e.message}));
  }
}

function doPost(e){
  try{
    const p = JSON.parse(e.postData.contents);

    // ── Photo upload → saves to Google Drive ─────────────────────────
    if(p.action === 'uploadPhoto'){
      const folder = getOrCreateFolder(DRIVE_FOLDER);
      const blob   = Utilities.newBlob(
        Utilities.base64Decode(p.photo),
        p.mimeType || 'image/jpeg',
        p.filename  || 'photo.jpg'
      );
      const file = folder.createFile(blob);
      file.setSharing(DriveApp.Access.ANYONE_WITH_LINK, DriveApp.Permission.VIEW);
      const url = 'https://drive.google.com/file/d/' + file.getId() + '/view';
      return ContentService.createTextOutput(JSON.stringify({url}))
        .setMimeType(ContentService.MimeType.JSON);
    }

    // ── Checklist submission → saves to Checklists sheet ─────────────
    if(p.action === 'checklist'){
      const ss = SpreadsheetApp.openById(SHEET_ID);
      let sh = ss.getSheetByName('Checklists');
      if(!sh){
        sh = ss.insertSheet('Checklists');
        sh.appendRow(['Date','Vehicle','Driver','All Passed','Notes','Photo URL','Submitted At']);
      }
      const r = p.record;
      sh.appendRow([r.date, r.vehiclePlate, r.driver,
        r.allPassed ? 'YES' : 'NO', r.notes||'', r.photoUrl||'', r.submittedAt]);
      return ContentService.createTextOutput('ok');
    }

    // ── Fleet data sync → saves to FleetJSON sheet ───────────────────
    if(p.chunks){
      const ss = SpreadsheetApp.openById(SHEET_ID);
      let sh = ss.getSheetByName('FleetJSON');
      if(!sh) sh = ss.insertSheet('FleetJSON');
      sh.clearContents();
      sh.getRange(1,1,p.chunks.length,1).setValues(p.chunks.map(c => [c]));
    }
    return ContentService.createTextOutput('ok');

  }catch(e){
    return ContentService.createTextOutput(JSON.stringify({error:e.message}));
  }
}
3
Deploy as a Web App

After pasting the code, click the blue Deploy button in the top right, then choose New deployment.

  • Type: select Web app
  • Description: Fleet Manager (any name)
  • Execute as: Me
  • Who has access: Anyone important
⚠️ Why "Anyone"? The tool needs to be able to send data from your browser without logging in each time. The URL itself acts as the password — anyone who has it can use it, so keep it private.

Click Deploy. Google will ask you to authorize the app — click Review permissions, choose your Google account, and click Allow.

After deploying, you'll see a Web app URL that looks like:

https://script.google.com/macros/s/AKfycb.../exec

Copy this URL — this is what you paste into the Fleet Manager tools.
4
Paste the URL into the Fleet Manager

On the desktop tool: The URL field is in the left sidebar under ☁️ Google Sheets Sync. Paste it there and click ⬆ Save to push your fleet data up for the first time.

On the mobile app: Go to ⚙️ Settings tab → ☁️ Google Sheets Sync section → paste the same URL. Then tap ⬇ Load to get the vehicle list from the office.

💡 Tip: Use the same URL for both tools — the same script handles everything (sync, photos, checklists).
5
What gets saved where

Once connected, here's what goes where automatically:

  • 🚛 Vehicle list, mileage logs, maintenance records → FleetJSON sheet (compressed data)
  • ☑️ Morning checklists → Checklists sheet (one row per submission, readable)
  • 📷 Inspection & damage photos → a Fleet Photos folder in your Google Drive, with a shareable link saved in the checklist/damage record
📁 The Fleet Photos folder is created automatically the first time a photo is uploaded. You can find it in drive.google.com.
6
If you make changes to the script later

If you ever need to update the Apps Script code, you must redeploy:

  • Click Deploy → Manage deployments
  • Click the pencil ✏️ edit icon on your deployment
  • Change version to New version
  • Click Deploy

The URL stays the same — you don't need to update it in the tools.

✅ That's it — your fleet is connected to Google. Photos go to Drive, checklists log to Sheets, and all data syncs across office and drivers.
